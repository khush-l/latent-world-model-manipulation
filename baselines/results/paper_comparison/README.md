# Same-Machine RopeFlatten Comparison

This folder contains the compact paper comparison for the fixed 50-episode
SoftGym RopeFlatten evaluation on one GPU machine.

## Setup

All models use `seed=0`, cached SoftGym config IDs `0..49`, a 75-step rollout
budget, and success threshold `0.8`.

| Model | Checkpoint / run |
|---|---|
| LeWM+CEM | `training/runs/final_rope_model_drive/final_rope_model.pt`, CEM horizon 5 |
| ACT | `outputs/train/act_rope_cem_final_25k/checkpoints/015000/pretrained_model` |
| SmolVLA | `outputs/train/smolvla_rope_cem_final_stronger/checkpoints/045000/pretrained_model` |
| pi0 LoRA | `/home/ubuntu/openpi/checkpoints/pi05_softgym_rope_lora/softgym_rope_cem_final_lora_40k_b4_ckpt5k/10000` |

## Metrics

Accuracy is normalized RopeFlatten performance in `[0, 1]`. The accuracy figure
plots max normalized performance over environment steps. LeWM uses saved MPC
performance traces. Direct-action runs only saved start and final performance,
so their curves interpolate between those measured values and show the 25th to
75th percentile band across the same 50 configs.

Latency uses milliseconds. ACT, SmolVLA, and pi0 report action-chunk forward
latency. LeWM+CEM reports a full CEM replanning call, so it should be read as a
planning-cycle cost rather than a single policy forward pass.
